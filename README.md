# netconf_mgmt

Library for managing RA2 device configuration and monitoring via NETCONF protocol. Provides Python API for connecting to devices, reading and writing YANG-modeled configuration, and handling NETCONF operations.

### Examples

Usage examples are in the `examples/` directory and can be run with `poetry run python examples/<script>.py`.

### Testing

Run inside the dev container:

```bash
poetry run pytest
```

### Linter checks

Run inside the dev container:

```bash
./lint.sh
```
